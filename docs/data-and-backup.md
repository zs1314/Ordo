# 数据与备份

任务、清单、手动交接记录、打卡和偏好保存在本机：

```text
~/Library/Application Support/Ordo/todo.db
```

替换应用不会移动或删除数据。应用的「文件」菜单可以打开数据文件夹。2.2 简化了界面，已有任务的标签、重复规则、日期与交接信息会保留。

## 导出

- **导出待办 JSON**：用于迁移任务和清单。
- **备份全部数据**：导出完整 SQLite 快照，包含任务、设置和日志，也保留旧版本已有的执行记录。

数据库备份不包括外部工作文件夹中的文件；旧版本的 `Agent Tasks/` 文件夹如有成果文件，请单独备份。

## 从完整备份恢复

1. 在应用的「文件」菜单打开数据文件夹，再按 ⌘Q 退出应用。
2. 将文件夹中的 `todo.db`、`todo.db-wal`、`todo.db-shm`（后两者如存在）移到另一个备份文件夹，不要删除唯一副本。
3. 将之前导出的完整 `.sqlite` 备份复制到数据文件夹，重命名为 `todo.db`。
4. 重新打开 Ordo。

JSON 可通过命令行工具 `backend/data.mjs import` 导入；它不包含完整日志和其他元数据，日常备份优先使用完整 SQLite 备份。

## 离线与网络

桌面待办和手动 Agent 分类不需要账号，可以离线使用。2.2 不连接或调用 Codex，记录 Agent 名称不会发送任务或执行命令。

Ordo 当前没有云同步。桌面服务只监听本机随机端口，并使用每次启动独立的会话认证。
