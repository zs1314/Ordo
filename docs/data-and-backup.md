# 数据与备份

普通待办不需要账号，任务、清单、打卡、偏好和执行记录保存在本机：

```text
~/Library/Application Support/Ordo/todo.db
```

替换应用不会移动或删除数据。应用的「文件」菜单可以打开数据文件夹。

## 导出

- **导出待办 JSON**：用于迁移任务和清单。
- **备份全部数据**：导出完整 SQLite 快照，包含任务、设置、日志和 Codex 执行记录。

Codex 在工作文件夹中生成或修改的文件不在数据库备份中，请单独备份这些文件。

## 从完整备份恢复

1. 在应用的「文件」菜单打开数据文件夹，再按 ⌘Q 退出应用。
2. 将文件夹中的 `todo.db`、`todo.db-wal`、`todo.db-shm`（后两者如存在）移到另一个备份文件夹，不要删除唯一副本。
3. 将之前导出的完整 `.sqlite` 备份复制到数据文件夹，重命名为 `todo.db`。
4. 重新打开 Ordo。

JSON 可通过原项目 `backend/data.mjs import` 导入；它不包含完整日志和 Canvas 状态，日常备份优先使用完整 SQLite 备份。

## Codex 与网络

开始执行时，所选任务的标题、备注、子任务和补充要求会交给本机 Codex。Codex 会在指定文件夹中执行，可能读取或修改该文件夹内的文件。执行需要网络，并使用本机登录账户的额度及配置。Ordo 不要求额外填写 API Key。

未选择工作文件夹时，Ordo 会在数据目录的 `Agent Tasks/` 中为本次任务创建独立文件夹。停止或退出会终止正在执行的进程，已生成的文件保留。关闭窗口不会中断执行。

Ordo 当前没有云同步。桌面服务只监听本机随机端口，并使用每次启动独立的会话认证。
